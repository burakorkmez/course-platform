## 🏗️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **UI:** Tailwind CSS + Shadcn UI
- **Auth:** Neon Auth
- **Database:** PostgreSQL (Neon)
- **Payments:** Polar
- **AI:** OpenAI
- **Storage/CDN:** ImageKit
- **AI Development:** Claude
- **Monitoring:** Sentry

## ⚙️ .env Setup

```bash
DATABASE_URL="<your_database_url>"

NEON_AUTH_COOKIE_SECRET="<your_neon_auth_cookie_secret>"

NEON_AUTH_BASE_URL="<your_neon_auth_base_url>"

ADMIN_EMAILS="<your_admin_email>"


IMAGEKIT_PUBLIC_KEY="<your_imagekit_public_key>"
IMAGEKIT_PRIVATE_KEY="<your_imagekit_private_key>"
IMAGEKIT_URL_ENDPOINT="<your_imagekit_url_endpoint>"
IMAGEKIT_ID="<your_imagekit_id>"
IMAGEKIT_FOLDER="<your_imagekit_folder>"


POLAR_MONTHLY_PRODUCT_ID="<your_polar_monthly_product_id>"
POLAR_LIFETIME_PRODUCT_ID="<your_polar_lifetime_product_id>"

POLAR_ACCESS_TOKEN="<your_polar_access_token>"
POLAR_SERVER="<your_polar_server>"

POLAR_WEBHOOK_SECRET="<your_polar_webhook_secret>"


OPENAI_API_KEY="<your_openai_api_key>"
```

## 🚀 Run the app

```bash
npm install

npm run dev
```
